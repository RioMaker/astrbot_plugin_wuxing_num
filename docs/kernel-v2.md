# 资料推演内核规则与边界

`document_v2` 的规则版本为 `2.0.0`。依据是工作区资料文件夹的《0数字卦.docx》。这份资料是课堂笔记，部分例题缺少过程且存在矛盾，因此本内核将原文规则、实现约定和未解决情形分开记录。它不再使用经典内核的环形打分，也不把资料不足解释为死卦。

## 明确规则

1. 数字为五个 0–9 单位数，允许前导 0 和重复数字。1/6 水、7/2 火、3/8 木、9/4 金、5/0 土，奇阳偶阴。
2. 原始五行先补齐，与问题无关；缺失项补阳。
3. 全阳无法按阴克阳起步，资料说一般将土转阴。
4. 从第一个阴开始，以阴克阳。15997 完整案例每轮消去主克方，被克方由阳变阴。
5. 推演所得余象需要与所问事项结合。完整案例交易取水，金克木接入水后形成金生水生木。
6. 生相对应可向达成发展；克相表示短期难实现，不等于永远失败。
7. 阴阳有不同象意：阳木为身体，阴木为精神与思虑；阳火为冲动，阴火为保守及内耗。不能固定认为阳总是根、阴总是表。

## 为执行而明确的约定

这些约定在页面可查看，使用阴生阴时会在结果中再次提示，不宣称全部来自原文。

- 补项按水、火、木、金、土顺序追加，保留输入位置及重复项。
- 全阳时将第一个土转阴。补齐后一定有土。
- 每轮从左向右扫描可执行的阴克阳，目标也取从左向右首个。没有可克目标的阴不会阻止扫描后面的阴。
- 若没有阴克阳可做，从右向左查找阴生阴：生者消去，受生者转阳。这条是根据简例整理的补充约定，需老师复核。
- 余两项即停止消去，避免把最终表示关系的“克”继续执行至只剩一项。
- 两项先尝试按相生方向排列，否则按相克方向排列。
- 事项五行已在余象时直接判断；不在时，只实现能形成完整相生链的中间阳五行插入。其他合卦情况返回待定。
- 同气、剩余多项且无可执行变化、事项不能接入、无法判断生克的组合，均为待定，不累计经典死卦次数。

每次消去都减少一项，所以推演有界、可终止。输入最多补四项，且每次结果保存规则版本。

## 应期

仅实现最终链为阳金、阳水、阴木时，资料明确列出的补数路径：

阴木 8 + 阳火 7 + 阴火 2 + 阳土 5 + 阴土 10 = 32。
去掉最后一项得到起始数 22。原文数字排列中的 2、7 与所写阴阳火顺序相反，这里按开头映射纠正，合计不变。

输入阴土用 0，应期求和用 10。单位默认“未定”：原文销售例使用天是因为其年货销售情境，不能推广为所有问题都按天计算。资料没有解释为什么补到土结束，不据此编造其他组合的通用应期算法。其他情况显示规则待补充。

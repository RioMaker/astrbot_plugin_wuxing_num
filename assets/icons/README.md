# 五行专属徽记

`wuxing_emblems.png` 由内置 imagegen 生成，用户提供的原神元素标志仅作风格参考。
采用纯色、尖端曲线、清晰镂空与幻想游戏徽记风格；五个图形专门表现水、火、木、金、土。金是金属刃面与菱形，不是雷。

图集为 1536 × 1024、3 列 × 2 行，单格 512 × 512：第一行水、火、木；第二行金、土、空白。背景为白色。
`element_icons.py` 运行时读取格子、测量非白色内容边界并等比例缩放到图卡圆章，保持源图不变。

首稿光晕过强，最终采用第二次修订的纯色白底版。完整提示词见 [generation_prompt.md](generation_prompt.md)。
